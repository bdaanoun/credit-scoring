MODEL REPORT
============

ALGORITHM
=========
We used XGBoost, a gradient boosting algorithm based on decision trees,
to predict the probability of loan default.

We chose XGBoost because it works well with tabular data and can capture
non-linear relationships between the features.

We used max_depth=5, min_child_weight=3, subsample=0.8,
colsample_bytree=0.8, and learning_rate=0.05 to control model complexity
and improve generalization.


WHY ACCURACY SHOULDN'T BE USED
===============================
We did not use accuracy as our main metric because the dataset is
imbalanced. There are significantly more clients who do not default
than clients who do.

A model could therefore achieve high accuracy by mostly predicting the
majority class while failing to identify clients who default.

We used ROC AUC instead because it measures how well the model
distinguishes between clients who default and those who do not,
independently of a single classification threshold.


OVERFITTING PREVENTION AND TRAINING STOPPING STRATEGY
=====================================================
We used several techniques to reduce overfitting:

- max_depth=5 limits tree complexity.
- min_child_weight=3 prevents overly specific branches.
- subsample=0.8 and colsample_bytree=0.8 add randomness during training.
- learning_rate=0.05 makes the model learn progressively.
- early_stopping_rounds=50 stops training when validation AUC no longer
  improves.

From the learning curve, we observed that training AUC continued to
increase while validation AUC eventually stopped improving. This
indicated that continuing to train would mainly increase overfitting.

We therefore selected the best iteration based on validation AUC and
stopped training after 50 rounds without improvement.


LIMITATIONS AND POSSIBLE IMPROVEMENTS
=====================================
We faced a few limitations during the project. The main one is that the
model's AUC is relatively close to the required threshold, so its
predictive performance could be improved.

Possible improvements include:

- Better feature engineering using more information from the datasets.
- More extensive hyperparameter tuning.
- Better handling of class imbalance.
- Comparing XGBoost with other models such as Logistic Regression or
  Random Forest.
- Using SHAP to improve the interpretability of individual predictions.
